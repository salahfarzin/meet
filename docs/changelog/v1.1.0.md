# v1.1.0 — 2026-02-06

Minor release. Previous: [v1.0.0](v1.0.0.md) · Next: [v1.2.0](v1.2.0.md) · Diff: `git log v1.0.0..v1.1.0`

## Features

- Health endpoints under the REST prefix: `/health`, `/live` and `/ready`. They bypass auth.
- API docs served from embedded files: a Scalar-based docs UI at `<prefix>/docs/`, plus
  `openapi.yaml` and a Postman collection.

## Changes

- The database pool, middlewares (auth, CORS, logging, JSON header) and config loading now
  come from the shared `github.com/salahfarzin/utils` package instead of local copies in
  `pkg/` (#12, #13).

## Fixes

- The log directory is created before the logger starts, so a fresh checkout or container
  no longer fails on a missing `storage/logs`.

## Infrastructure

- End-to-end tests (#10, #11) against a Docker Compose stack (`docker-compose.test.yml`),
  with auth swapped for a test middleware under `APP_ENV=test`.
- CI runs migrations with the golang-migrate CLI, and skips integration tests when there
  are none.
