# v1.0.0 — 2026-01-11

Initial release. Next: [v1.1.0](v1.1.0.md)

## Features

- gRPC server plus a grpc-gateway REST proxy for meets (appointments), backed by MySQL.
  `MeetService` covers list, get, create, update and delete, and rejects a meet that
  overlaps another meet of the same organizer.
- Organizer availability (#1, #2): `GetAvailability` returns bookable slots per day
  (the next 7 days by default), and `GetMeetTypes` lists the meet types.
- Meets carry a price (`price_uuid`) and participants (`participant_uuids`) (#8, #9).
- Auth is delegated to the auth service: the REST gateway resolves the bearer token via
  `AUTH_SERVICE/me` and forwards the user as gRPC metadata. Only `Programmer` may set an
  arbitrary `organizer_uuid`.
- Configurable CORS origins.

## Infrastructure

- CI/CD (#3, #4): lint, tests, gosec and dependency review on PRs; a Docker image pushed
  on push to `main`, tagged `latest` and the commit sha.
- golangci-lint pipeline fixes (#6, #7), and pre-commit hooks in `.githooks`.
- Migrations run from the container entrypoint.
