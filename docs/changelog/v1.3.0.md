# v1.3.0 — 2026-09-28

Minor release. Previous: [v1.2.1](v1.2.1.md) · Next: [v1.4.0](v1.4.0.md) · Diff: `git log v1.2.1..v1.3.0`

## Features

- Specialties catalogue for trappists' public profiles (#18, #19). `SpecialtyService`
  manages an admin-curated list of specialties and therapy approaches (`kind`), with
  per-locale `names`, `sort_order` and an `active` flag.
  - `GET /meets/specialties` is open to any authenticated caller; `include_inactive` is
    honored for admins only.
  - Create, update and delete are for `Admin` and `Programmer`. Delete is a hard delete.
  - Trappists store only the uuids, so hidden or deleted entries drop off patient-facing
    profiles.
  - Seeded with an initial set of specialties and approaches.

## Infrastructure

- `.env.example` uses ports 8083 / 9093 to match `docker-compose.prod.yml`, and drops
  unused variables.

Migrations: `000003_create_specialties_table`, `000004_seed_specialties`.
